# CopySelect build records

This folder travels with packaged builds so development context is not separated from the code it describes.

- `PROJECT_HANDOFF.md`: current developer handoff/spec and continuity notes.
- `RUNNING_CHANGELOG.txt`: cumulative implementation changelog.
- `RUNNING_FIX_AUDIT.md`: cumulative bug/fix audit and verification record.
- `PANEL_FINDINGS_3.7.8.13.md`: current review findings.
- `PANEL_REVIEW_PROMPT_3.7.8.13.md`: review prompt used for the current RC.

For future releases, these files should be updated in place before packaging so each ZIP remains a self-contained development checkpoint.
